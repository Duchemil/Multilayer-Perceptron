Notes : 
Foward propagation is the process in which input data passes through multiple layers to generate an output.

You pass the input through the input layer, then to a hidden layer which computes an output through weighted sum and bias, to an activation layer which applies an activation function, to another hidden layer and so on until you reach the output layer which gives the prediction.

Backward propagation is the process of adjusting the weights and bias depending on the expected output and the received output.
